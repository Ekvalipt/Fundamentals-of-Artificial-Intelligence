### 1. Пояснення
**Запит:** Коротко поясни, що таке ORM у Django.
**Відповідь:**
ORM (Object-Relational Mapping) у Django — це система, яка дозволяє працювати з базами даних, використовуючи об'єктно-орієнтоване програмування. Замість написання SQL-запитів, розробники можуть використовувати Python-класи для визначення моделей, які представляють таблиці бази даних. ORM автоматично перетворює ці моделі в SQL-команди для виконання операцій з даними.

Переваги використання ORM у Django:
* Спрощення роботи з базою даних: розробники можуть зосередитися на коді, а не на SQL.
* Портативність: код можна легко переносити між різними СУБД.
* Захист від SQL-ін'єкцій завдяки автоматичному екрануванню вхідних даних.

Таким чином, ORM у Django робить взаємодію з базою даних інтуїтивно зрозумілою та ефективною.

## ЗАВДАННЯ 2: ПОРІВНЯННЯ ZERO-SHOT ТА FEW-SHOT

### Підхід: Zero-shot
**Запит (без прикладів):** Напиши SQL запит для вибірки всіх користувачів.
**Відповідь:**
Звичайно! Якщо у вас є таблиця, назвемо її `users`, яка містить інформацію про користувачів, ви можете використати наступний SQL запит для вибірки всіх користувачів:
```sql
SELECT * FROM users;
```
Цей запит вибирає всі стовпці (`*`) з таблиці `users`. Якщо вам потрібно вибрати конкретні поля, ви можете замінити `*` на назви стовпців, які вас цікавлять, наприклад:
```sql
SELECT id, username, email FROM users;
```
Цей запит вибере тільки стовпці `id`, `username` та `email`.

### Підхід: Few-shot
**Запит (із прикладами):**
Приклад 1: Вибрати імена -> SELECT name FROM users;
Приклад 2: Вибрати email -> SELECT email FROM users;
Завдання: Напиши SQL запит для вибірки всіх користувачів.
**Відповідь:**
Для вибірки всіх користувачів з таблиці `users` ви можете використати наступний SQL запит:
```sql
SELECT * FROM users;
```
Цей запит вибирає всі стовпці (`*`) з таблиці `users`.
